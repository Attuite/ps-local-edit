# Photoshop 局部 AI 改图插件

Photoshop 内的简洁 UXP 面板，使用 PS 原生选区完成局部修改。本 Fork 由 Attuite 维护，保留 LK888 任务接口，并加入自定义 OpenAI 兼容图片编辑 API。

0.1.5 修复选择历史后下方内容不切换：按 UXP 下拉框的 `selectedIndex` 获取对应记录，并同步当前选中项；不依赖可能仍保存旧 ID 的 `.value`。输入页与结果页继续通过同一记录恢复流程更新。参考 [Adobe 下拉框事件说明](https://developer.adobe.com/photoshop/uxp/2021/uxp/reference-spectrum/User%20Interface/sp-dropdown/)。

0.1.4 将顶部多行标签改为收起的「历史记录」下拉选择，保留全部旧记录及新建改图功能。切换记录前保存当前输入，后台状态更新不会重建已展开的菜单。

0.1.3 为整个面板增加纵向滚动条，长设置页及改图页均可向下滚动；面板高度随 Photoshop 面板大小调整。

## 耗时诊断（Attuite 0.1.2）

正常使用时自动记录提交与每次状态查询的时间；「设置 → 导出耗时记录」可保存 JSON。「检查已有任务状态」只对最近一笔 LK888 历史任务发送一次 GET 查询，不提交生图，不覆盖历史图片或任务状态。没有 LK888 历史任务时不会发请求。

记录包括本机密钥读取完成、请求发出、响应头到达、响应体读取完成、超时回调触发、查到终态、实际轮询间隔和因查询尚未返回而跳过的轮询次数。响应头仅记录 Date、Age、Cache-Control、X-Cache、CF-Cache-Status、Via，用于辅助判断缓存；不读取或导出 Authorization。每个任务保留最近 200 次查询及累计次数，记录仅保存本机，不包含 API Key、提示词、输入/结果图片或结果 URL。

此版本保持原来的 4 秒轮询、60 秒状态请求超时及生成参数，不通过改超时掩盖原因。若单次请求到响应头接近 60 秒且记录了超时，可定位到请求链路等待；若实际 timerGapMs 接近一分钟而 HTTP 很快，则指向宿主定时器调度延后；若请求很快却持续返回旧状态，需要结合响应缓存头和平台实际完成时间判断。HTTPS 代理是否经过某节点需结合代理连接日志，不能仅靠 Via 头确定。旧任务的已结束请求无法补录。

## 自定义 API（Attuite 0.1.1）

1. 打开「设置」，接口类型选择「OpenAI 兼容 · 图片编辑」。
2. 填写服务的 Base URL（通常是 `https://你的服务/v1`）与自己的 API Key，点击「保存连接设置」。只填写域名会自动补 `/v1`；带自定义路径的地址按原样使用。
3. 在「模型管理」输入服务支持的图像编辑模型 ID，点击「添加 / 更新」。也可从 API 刷新模型列表。
4. 返回改图，选择该模型、清晰度与尺寸后生成。检查连接仅请求 `/models`，不提交生成任务。

此模式使用 `POST <Base URL>/images/edits`，以 multipart 上传原始图片，支持同步返回的 `data[].b64_json` 或 HTTPS `data[].url`。单图字段是 `image`，多图字段是 `image[]`；服务需要支持相应格式。参考 [OpenAI 官方接口说明](https://developers.openai.com/api/reference/resources/images/methods/edit)。聊天、Responses、Gemini 原生和其他异步任务协议暂不支持；LK888 可继续选择原有模式。

每张结果单独请求一次，最多 4 张。同步生成在后台进行，最长等待 5 分钟；网络中断或 PS 退出后不能查询该同步请求，须先到服务平台核对，避免重复计费。已返回的图片保留在历史记录。API 地址和模型列表保存本机，密钥按接口类型和地址分别存入 UXP secureStorage；历史任务保留提交时的地址，切换服务不会把旧任务或旧密钥发送给新地址。远程地址要求 HTTPS，本机 localhost 可用 HTTP。

OpenAI 模式的尺寸是模型输出尺寸，回填仍按原选区尺寸缩放并使用原蒙版。更换接口后，应重新选择适用的清晰度与尺寸。默认模型只是示例，是否可用以你配置的服务为准。

## 功能

- 框选或套索读取选区，紧贴选区捕获参考画面并保留原选区蒙版。
- 添加、拖入或粘贴截图作为编号参考图。
- 输入修改要求，选择模型、清晰度、尺寸及 1–4 张结果。
- 多处改图可后台生成；通过顶部「历史记录」下拉框切换，恢复对应输入及结果。
- 结果点击添加独立图层，按原坐标和尺寸回填；允许重复添加。
- 图片右上角放大预览，预览内下载或右键保存原图。
- 设置页保存 API Key、刷新 API 模型列表及手动管理模型 ID。
- 语音按钮提示使用 Windows 的 Win+H 听写。

## 安装

需要 Photoshop 25.1 或更新版本。上游作者报告 Photoshop 27.6 已加载并完成实际生成与图层回填；该报告不代表本 Fork 的验证结果。不同宿主和模型仍需自行验证。

1. 尝试双击 `dist/局部改图-Attuite-0.1.5.ccx` 使用 Creative Cloud 安装。
2. 若本地 CCX 无法安装，通过 Adobe UXP Developer Tool 添加 `plugin/manifest.json`，点击 Load。
   若已安装 Adobe 官方 UXP CLI，也可运行 `./scripts/load-local.ps1`，或使用 `-UxpCommand` 指定 CLI 路径；Photoshop 必须启用开发模式并返回主界面。
3. 在 PS 增效工具中打开面板，进入设置选择接口，填写并保存自己的 API 地址和 Key。
4. 在 RGB 文档选择区域，点击更新选区，输入要求后生成。
5. 生成完成后点击候选图添加图层。放大查看与添加操作分开。

更新后还需在 Photoshop「帮助 → 系统信息」确认实际加载的版本；安装器显示 Enabled 不代表当前会话已切换。若同一插件残留多个版本登记，先备份本机 `UXP/PluginsStorage/PHSP/<主版本>/External/com.local.lk888.psedit`，再清理旧登记并恢复数据、安装最新版。Adobe 卸载可能移除该 ID 的共享设置与历史，不能直接卸载后丢弃备份。

密钥保存在本机 UXP secureStorage。模型列表可能包含聊天模型，只有平台支持的图像编辑模型才能完成改图。模型可用性、速度及费用以平台账号为准。一次生成多张会提交多个任务。

## 开发

核心测试无需额外依赖，使用 Node.js 执行：

```sh
node --test tests/*.test.cjs
```

Windows 打包：

```powershell
./scripts/package.ps1
```

浏览器检查脚本使用 Playwright；本机版本引用了本地运行时路径，其他环境需调整引用。

## 边界

生成与添加图层分开。历史保存输入和结果，但导入时必须回到原文档，画布尺寸变化会阻止自动导入。输入图片和提示词发送到设置中保存的 API 服务；图片下载不附带 API Key。原选区蒙版限制显示区域，模型可能改变区域内构图。输入 PNG 无损编码，结果保存模型原始文件；回填缩放和模型输出分辨率仍会影响显示细节。
